# VLA HUD v0.2.0

Subscription-free personal operating system designed for iPhone installation through GitHub Pages.

## New in v0.2

- Automatic 21-day Domino Sugar rotation
- Anchor date: July 29, 2026
- Vacation overlay: August 7–13, 2026
- Vacation countdown and underlying cycle visibility
- To Do, Acquire, Packing, and Itinerary lists
- Due-today task display
- Automatic Workday, Recovery, Growth, Open, and Vacation modes
- Manual mode override
- Data export/import backup
- Existing v0.1 progress and inbox data migration

## Update the live GitHub Pages site

Upload and replace these files in the repository root:

- index.html
- app.js
- styles.css
- service-worker.js
- manifest.webmanifest
- icon.svg
- README.md

Commit the changes to `main`. GitHub Pages republishes automatically. Open the Home Screen app while online and refresh/reopen it to receive the new service-worker version.
